# 🚀 پیام‌رسان وب پیشرفته (Advanced Web Messenger)

## 🚀 نصب و راه‌اندازی

### پیش‌نیازها
- PHP 7.4 یا بالاتر
- MySQL 5.7 یا بالاتر (با پشتیبانی از Partitioning)
- وب‌سرور Apache یا Nginx
- فعال بودن PDO MySQL

### مرحله ۱: ساخت دیتابیس

```bash
# وارد MySQL شوید
mysql -u root -p

# دیتابیس بسازید
CREATE DATABASE messenger_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

# ایمپورت اسکما
mysql -u root -p messenger_db < db_schema.sql
```

### مرحله ۲: تنظیم config.php

فایل `config.php` را ویرایش کنید:

```php
define('DB_HOST', 'localhost');
define('DB_USER', 'root');        // نام کاربری دیتابیس
define('DB_PASS', '');            // رمز عبور دیتابیس
define('DB_NAME', 'messenger_db');
define('APP_URL', 'http://localhost/messenger');
```

### مرحله ۳: تنظیم مجوزها

```bash
chmod -R 755 messenger/
chmod -R 777 messenger/uploads/
chmod -R 777 messenger/logs/
```

### مرحله ۴: ورود به سیستم

**ادمین پیش‌فرض:**
- شماره تلفن: `0000000000`
- رمز عبور: `admin123`

**پنل مدیریت:**
- آدرس: `http://localhost/messenger/admin/`

## 🎯 راهنمای استفاده از ویژگی‌ها

### ۱. مدیریت تیک‌ها (Badges)

در پنل مدیریت → تب "تیک‌ها و محدودیت‌ها":
- محدودیت استوری برای هر سطح را تنظیم کنید
- به کاربران تیک آبی، طلایی یا مشکی بدهید

### ۲. کنترل ثبت‌نام

در پنل مدیریت → تب "تنظیمات سیستم":
- **ثبت‌نام کاربران**: فعال/غیرفعال کردن ثبت‌نام عمومی
- **حالت تعمیرات**: فقط ادمین‌ها می‌توانند وارد شوند
- **رزرو آیدی**: آیدی‌های خاص را رزرو کنید

### ۳. سیستم گزارش‌دهی

کاربران می‌توانند:
- پیام‌ها را با منوی سه‌نقطه گزارش دهند
- پروفایل کاربران را گزارش دهند

ادمین در پنل → تب "گزارش‌ها":
- گزارش‌ها را بررسی کند
- پیام را حذف کند
- کاربر متخلف را بن کند

### ۴. بن و رفع بن

**بن کردن کاربر:**
1. پنل مدیریت → تب "کاربران"
2. انتخاب کاربر → عملیات "مسدود کردن"
3. وارد کردن دلیل بن

**درخواست رفع بن:**
1. کاربر بن‌شده به `banned.php` هدایت می‌شود
2. فرم درخواست بررسی مجدد را پر می‌کند
3. ادمین در تب "درخواست‌های بن" بررسی می‌کند

### ۵. حذف اکانت

وقتی کاربری حذف می‌شود (#159, #160):
- نام او به "Deleted Account" تغییر می‌کند
- عکس پروفایل حذف می‌شود
- پیام‌های او باقی می‌مانند اما با نشان حذف‌شده

## 📊 دیتابیس

### جداول اصلی

| جدول | توضیح |
|------|-------|
| `users` | اطلاعات کاربران با تیک‌ها و حریم خصوصی |
| `chats` | چت‌ها، گروه‌ها و کانال‌ها |
| `messages` | پیام‌ها (Partitioned by Date) |
| `chat_participants` | اعضای چت و دسترسی‌ها |
| `stories` | استوری‌های کاربران |
| `message_reports` | گزارش‌های پیام |
| `user_reports` | گزارش‌های کاربر |
| `ban_appeals` | درخواست‌های رفع بن |
| `reserved_handles` | آیدی‌های رزروشده |
| `system_settings` | تنظیمات پویای سیستم |
| `admin_logs` | لاگ اقدامات ادمین |

### Partitioning پیام‌ها

جدول `messages` به صورت خودکار بر اساس تاریخ پارتیشن‌بندی شده است:
- p0: قبل از ۲۰۲۴-۰۱-۰۱
- p1: ۲۰۲۴-۰۱-۰۱ تا ۲۰۲۴-۰۶-۰۱
- p2: ۲۰۲۴-۰۶-۰۱ تا ۲۰۲۵-۰۱-۰۱
- p3: بعد از ۲۰۲۵-۰۱-۰۱

این امکان مدیریت میلیون‌ها پیام را فراهم می‌کند.
