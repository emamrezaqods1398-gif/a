# پیامرسان وب با PHP

یک پیامرسان وب کامل شبیه به واتساپ با قابلیت‌های زیر:

## ویژگی‌ها

### کاربران
- ثبت نام و ورود امن
- پروفایل کاربری
- نقش‌های کاربری (کاربر عادی و ادمین)

### چت
- **چت خصوصی**: گفتگوی یک‌به‌یک بین کاربران
- **گروه**: ایجاد گروه با چندین عضو
- **کانال**: کانال برای انتشار پیام به تعداد زیادی کاربر

### استوری
- آپلود عکس و ویدیو به عنوان استوری
- استوری‌ها بعد از 24 ساعت منقضی می‌شوند
- مشاهده استوری دیگران

### پنل مدیریت
- مشاهده آمار کلی (تعداد کاربران، چت‌ها، پیام‌ها، استوری‌ها)
- مدیریت کاربران
- حذف کاربران

### UI/UX
- طراحی شبیه به واتساپ
- پشتیبانی کامل از زبان فارسی (RTL)
- ریسپانسیو برای موبایل و دسکتاپ
- تم سبز رنگ مشابه واتساپ

## نصب و راه‌اندازی

### پیش‌نیازها
- PHP 7.4 یا بالاتر
- MySQL 5.7 یا بالاتر
- Apache/Nginx با پشتیبانی از PHP

### مراحل نصب

1. **ایجاد دیتابیس**
   ```bash
   mysql -u root -p < db_schema.sql
   ```

2. **تنظیمات اتصال به دیتابیس**
   
   فایل `config.php` را باز کنید و اطلاعات دیتابیس خود را وارد کنید:
   ```php
   define('DB_HOST', 'localhost');
   define('DB_NAME', 'web_messenger');
   define('DB_USER', 'root');
   define('DB_PASS', 'رمز_عبور_دیتابیس');
   ```

3. **تنظیم مجوز پوشه uploads**
   ```bash
   chmod -R 755 uploads/
   ```

4. **ورود به برنامه**
   - آدرس برنامه را در مرورگر باز کنید
   - با حساب ادمین پیش‌فرض وارد شوید:
     - نام کاربری: `admin`
     - رمز عبور: `password`

## ساختار فایل‌ها

```
├── config.php              # تنظیمات و اتصال به دیتابیس
├── index.php               # صفحه اصلی چت
├── login.php               # ورود کاربر
├── register.php            # ثبت نام کاربر
├── logout.php              # خروج
├── new_chat.php            # ایجاد چت جدید
├── story.php               # مدیریت استوری‌ها
├── db_schema.sql           # اسکیمای دیتابیس
├── api/
│   └── send_message.php    # API ارسال پیام
├── admin/
│   └── index.php           # پنل مدیریت
├── assets/
│   ├── css/
│   │   └── style.css       # استایل‌های برنامه
│   └── js/                 # فایل‌های جاوااسکریپت
└── uploads/
    └── stories/            # محل ذخیره استوری‌ها
```

## امنیت

- استفاده از Prepared Statements برای جلوگیری از SQL Injection
- هش کردن رمز عبور با الگوریتم bcrypt
- توکن‌های امنیتی برای عملیات حساس
- بررسی سطح دسترسی کاربران

## کاربران پیش‌فرض

| نام کاربری | رمز عبور | نقش |
|-----------|---------|-----|
| admin     | password | مدیر |
| ali       | password | کاربر |
